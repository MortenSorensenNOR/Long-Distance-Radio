# Long distance Radio Project  
Project for teaching myself PCB and RF design. Goal is to design, manufacture and test a self-designed radio system that can transmit 1 MBits/s of information using license exempt bands, primarily a 250 kHz 869.4 to 869.65 MHz band in Norway.   
The radio itself will be split into four separate PCBs (since I don't really know what I'm doing), mainly an ADC/DAC board, a mixer board, an LO board and an LNA and PA board.
